Projects

RepCinema — London repertory cinema listings
Website

London's repertory film screenings — classics, restorations and prints at over 80 venues — published as an Android app, a monthly Google Sheet and a website. Behind it: Playwright and Selenium scrapers, a Claude API scraper for venues without their own, a weekly check for new and dropped screenings, and a Supabase database the app reads.

Python Playwright Java Selenium Jest React Native Testing Library Appium Kiwi TCMS Jenkins GitHub Actions Claude API Claude Code Supabase React Native Cloudflare

Testing

  • Unit — Jest tests for the app's shared rules (showtimes, title cleaning, same-film matching, booking links), run on every pull request
  • Component — screens rendered from fixed data with React Native Testing Library, no phone needed
  • Device end to end — Appium (Java) on a real Android phone, in progress
  • Contract — the same titles run through the Python, Java and TypeScript title rules; the test fails if any two disagree
  • Reporting — results recorded in Kiwi TCMS automatically, matched to each test case by its number

CI/CD jobs

  • Jenkins, nightly — Playwright (Python) and Selenium (Java) scrapers write a dated CSV per venue
  • Jenkins, weekly — a Claude API scraper for about 90 smaller venues and ticket sites, then a comparison against the database and emailed review files
  • Jenkins, monthly — compile the month's working sheet, promote it to the release candidate, and build the published sheet from the database; Claude Code copies the Drive files
  • Jenkins, membership — a daily Patreon/Wix membership check with an email report, and sheet access granted by membership tier
  • Jenkins, health — a daily check that the build machine's Claude Code login hasn't lapsed
  • GitHub Actions — lint, build and unit tests on every pull request; a listing health check; a database keep-alive
  • Cloudflare Pages — the website published on every merge, with a preview for each pull request

Pipeline

Nightly scrapers→ Weekly compare→ Review→ Supabase→ App & sheet
